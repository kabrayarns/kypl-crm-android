KYPL CRM Android wrapper (source project)
URL: https://crm.kabrayarns.com/
Open folder in Android Studio; allow Gradle sync and SDK 35 installation.
Build > Build Bundle(s) / APK(s) > Build APK(s).
Debug APK: app/build/outputs/apk/debug/app-debug.apk
For distribution to employees, use Build > Generate Signed Bundle / APK > APK and keep the signing key secure.
This project is NOT a compiled APK. Test login, OTP, downloads, upload, and navigation on a physical phone before distribution. Website and database remain on your existing server.
